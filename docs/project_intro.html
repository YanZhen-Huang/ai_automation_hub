02四大客户端

同样的数据，不同的使用场景

桌桌面端（主力）

Python 3.13 · tkinter · pystray

常驻托盘的完整工作台，七个页签覆盖会议全流程，右侧待办实况窗置顶提醒。

  • 会议准备：一/二阶段动作项看板，waiting 项人工确认
  • 智能采集：AI 定位窗口 → 模拟点击会话 → OCR 读取提炼
  • 运行状态：服务、进程、数据统计、日志实时可见

网Web 端

FastAPI · Vue3(CDN) · 5 秒自动刷新

浏览器即开即用，与桌面端功能一致，适合不装软件的场合查看。

  • 会议看板：进度实时刷新，动作日志追踪
  • 设置中心：18+ 项配置表单化，保存即落盘
  • 手机直达：小程序生成二维码，扫一下即开 Web 端

微微信小程序（会议管家）

原生小程序 · 手机轻操控

「手机随手看 + 轻操控」：不开电脑也能盯进度、点确认、录信息、扫码签到。

  • 首页看板：最近会议 + 阶段进度条 + 待办角标
  • 扫码签到：扫参会人员二维码一键到场，名单实时同步
  • 扫一扫入库：扫码内容可编辑后提交，交 AI 提炼

鸿鸿蒙手机 App

ArkTS · 电话 + TTS + 录音转文字

自动完成「打电话」类动作：拨打 → 语音播报请求 → 录音识别对方答复 → 回传确认。

  • 订会议室 / 茶水 / 服务 / 设施：电话话术自动播报
  • 回传联动：桌面端动作项自动置为完成，二阶段自动推进

06一次会议的生命周期

信息入库→ AI 提炼→ 创建会议→ 一阶段 8 项并行→ 人工确认→ 二阶段串行→ 会议就绪

壹一阶段 · 8 项并行

  • 打电话：会议室 / 茶水 / 服务 / 设施（鸿蒙 App 自动拨打+播报）
  • 材料：AI 深度材料 → 自绘 PPT → md→PDF → 微信发印刷
  • 通知：微信自动下发或生成通知文本
  • 人工：确定会议时间、签字表

贰二阶段 · 串行推进

  • 与会人员：人工确认（印刷份数 = 人数 + 5）
  • 桌牌：电话安排
  • 审查：材料人工审查
  • 接待：自动提醒

辅降级与容错

  • 无 AI Key：关键词规则降级提炼，材料仍可生成
  • 微信发送失败：降级为生成通知文本
  • 断网：核心功能全部本地运行，不依赖云端
