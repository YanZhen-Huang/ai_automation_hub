## 一、项目概述

**会议准备自动化工作台**是一个「多源信息收集 → AI 提炼 → 固定工作流自动执行 → 桌面/Web/鸿蒙三端可视化 + 手机联动」的**会议前准备自动化系统**。

系统从微信、钉钉、飞书、OneNote、OCR、手动录入、录音等多渠道采集会议相关信息，AI 深度提炼，按固定工作流自动筹备一场会议：订会议室、安排茶水/服务/音响设施、AI 撰写汇报材料并生成 PPT/PDF、微信交付印刷（份数=与会人数+5）、微信下通知、定签字表、排桌牌、提醒接待；同时产出待办任务并常驻提醒。其中「打电话」动作由鸿蒙手机端 App 以「普通电话 + 语音播报 + 录音转文字」自动完成并回传确认信息。

## 二、背景与目标

**用户角色**：技术科科长（会务 + 技术管理双重场景）。

**核心诉求**：
- 会前有大量重复、并行的事务性电话与材料工作，需要自动化
- 关键环节（选会议室、定人员、审批、发文件）需**人工决策**，其余交给 AI
- 信息一旦采集，应**同时**服务「会议准备」与「待办任务」两类产出（信息库互享）
- 所有环节 **AI 自动 / 人工操作双线可选**，人工可全程接管

**设计原则**：
1. 固定工作流 = 一阶段并行 + 二阶段串行（不做通用编排引擎）
2. 一切自动化动作执行前**必须人工审批**
3. 打电话由鸿蒙手机端完成，桌面端只生成话术与目标
4. 全系统「降级可用」：无 AI Key → 规则；无微信 → 生成文本；手机不在线 → 超时重试不卡死

## 五、关键业务设计

### 5.1 固定工作流
```
一阶段（并行）：订会议室→茶水→服务→音响设施→材料/PPT/印刷→定时间→微信通知→签字表
二阶段（串行）：定与会人员→桌牌→人工审查→提醒接待
```
- **审批**：所有自动化动作先进入「待审批」，人工批准后执行
- **依赖前置**：订会议室先选房、桌牌/印刷先定与会人员（份数准确）

### 5.2 材料/PPT/印刷三步 + 双线
```
AI 生成材料 → 自绘 PPT + md + PDF（按会议分组 data/out/{会议}/）→ 微信发印刷 → 电话确认
├─ AI 自动：审批通过全自动
└─ 人工   ：材料 JSON 可编辑、PPT 手动生成、文件可指定发送
```

### 5.3 智能采集（AI + 模拟操作 + OCR）
```
定位前台窗口 → 读会话列表 → AI 筛选（重点对象→技术科相关→综合）→ 模拟点击各会话
→ OCR 消息区 → 提炼入库（会议要点+待办）→ 单轮自动停
```

## 九、使用方式

```
.venv\Scripts\python main.py     # 启动（桌面 + Web 8780 + 手机 8781）
```
1. 设置页填 DeepSeek Key / 配置采集与号码
2. 信息采集 → AI 自动提炼会议要点与待办
3. 新建会议（选 AI 自动/人工）→ 一阶段并行准备
4. 桌面/Web 审批、选会议室、定人员、材料/文件区操作
5. 鸿蒙端拉取打电话任务 → 拨打/播报/录音回传
6. 运行状态页/实况窗实时监控
