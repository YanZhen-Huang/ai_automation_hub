# ai_automation_hub · 个人自动化工作台

**定位**：个人自动化工作台——采集多源信息 → AI 提炼与决策 → 自动执行 → 桌面/Web 双端可视化。

**技术栈**：Python 3.13 全家桶（tkinter 桌面端、FastAPI + Vue(CDN) Web 端、SQLite 存储、DeepSeek/OpenAI 兼容 LLM）。

**提示**：该项目不完整！未经过测试！由AI编写！可能有未知漏洞！手机端仅支持HarmonyOS！

## 顶层结构

```
core/        底座      事件总线 | 调度器 | 配置中心 | 日志
collectors/  采集      IM(微信/钉钉/飞书) | 手动输入 | 录音转文字 | 网页 | 文件
ai/          智能      LLM 接入 | 信息提炼 | 决策规则 | 智能体
desktop/     桌面端    托盘 | 主窗口 | 组件
server/      Web 端    FastAPI 后端 | 前端页面 | 实时推送(WS)
automation/  执行      动作库(重点) | 固定工作流
storage/     存储      SQLite / JSON / 文件
tests/  data/  docs/
```

## 分阶段计划

- **阶段 1（已完成）**：底座(core) + 采集(微信/手动/录音) + AI 提炼 + 桌面端 + Web 端 + 固定会议准备工作流 + 手机联动
- **阶段 2**：微信 UIA 自动发送、OCR 采集、手机端录音转文字真机联调
- **阶段 3**：智能体 + 网页/文件采集 + 工作流编排细化

## 启动

```
python main.py
```
- 桌面窗口 + 系统托盘；Web 端 http://127.0.0.1:8780
- 手机联动端口 8781（鸿蒙端 phone_app/ 拉取打电话任务）

## 快速使用

1. 打开桌面端「信息采集」页，手动录入或自动采集信息；
2. 「会议准备」页新建会议 → 自动进入一阶段并行准备（打电话/材料/通知）；
3. 人工确认项在 Web 或桌面端点击确认；
4. 手机 App 拉取打电话任务 → 拨打 + 语音播报 → 录音转文字回传确认。
